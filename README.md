# Kotlin Expense Tracker

A REST API for tracking personal expenses, built as a project to learn Kotlin and Spring Boot.

## Tech Stack

- Kotlin
- Spring Boot
- Spring Data JPA
- Hibernate
- PostgreSQL
- Gradle

## Current Features

- Create expenses
- Retrieve all expenses
- Request validation
- Global exception handling
- PostgreSQL persistence
- Automatically generated UUIDs
- Automatically generated creation timestamps

## Architecture

HTTP Request
→ Controller
→ Service
→ Repository
→ Spring Data JPA
→ Hibernate
→ PostgreSQL
